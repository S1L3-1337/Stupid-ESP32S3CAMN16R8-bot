#Stupid-ESP32S3CAMN16R8-bot
Stupid MicroPython camera bot for the ESP32S3CAM-N16R8. Built with custom firmware and a bunch of modules, aggressively abusing the 8MB SPIRAM and 16MB flash size.
- **MCU Model**: ESP32-S3-CAM-N16R8 (16MB Flash, 8MB Octal SPIRAM)
- **Custom Firmware**: [cnadler86/micropython-camera-API](https://github.com/cnadler86/micropython-camera-API)
- **JPEG Encoder**: [cnadler86/mp_jpeg](https://github.com/cnadler86/mp_jpeg) (included in the firmware build)
